# Original baseline source mirrors

This folder contains source-only mirrors of the two baseline repositories used
for the COREX experiments:

- `pfairdp/`: https://github.com/apaleyes/dp-fairness-multi-objective-bayesian-optimisation
- `fairdp/`: https://github.com/khangtran2020/FairDP

Only code and lightweight project metadata are included. The upstream `.git`
directories, datasets, generated experiment CSVs, notebooks, caches, logs, and
model artifacts are intentionally excluded from this repository.
